# NEON — Marketing Intelligence OS

Интерактивный UI/UX-прототип единой SaaS-платформы для маркетологов и владельцев бизнеса.

## Запуск
Откройте `index.html` в современном браузере. Для локального сервера можно использовать:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Концепция
- Fintech + Hacker: тёмная графитовая основа, неоновый зелёный `#39FF88` и фиолетовый `#A78BFA`.
- Отдельные продуктовые пространства с общей оболочкой: Ad Intelligence, Ad Automation, SEO Intelligence, Website Builder и Analytics.
- Адаптивная раскладка для desktop, tablet и mobile.
- Общие паттерны UI: боковая навигация, переключение рабочего пространства, карточки KPI, график, таблица кампаний, лента событий, модальное окно создания проекта, toast-уведомления, фильтр таблицы и CSV-экспорт.

## Важно
Это front-end прототип. Показатели, кампании, события и лимиты — демонстрационные данные. Авторизация, сохранение проектов на сервере, реальные интеграции с рекламными платформами, биллинг, права доступа и парсер не подключены. Перед production потребуется согласовать API/архитектуру, реализовать backend, тесты и доступность.
